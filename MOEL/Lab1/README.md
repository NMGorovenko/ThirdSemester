# Лабораторная работа №1 - Токенизация и анализ тональности

## Задача
Для любого (на выбор магистранта) документа или набора документов написать токенизатор, провести нормализацию полученного словаря (стемминг, лемматизация, синонимия, стоп-слова и т.п.) и построить простой анализатор тональности текста на естественном языке (на основе метода VADER-правил или наивного байесовского классификатора).

## Структура проекта
- `notebook.ipynb` - основная тетрадка с кодом
- `data/` - папка с датасетом (CSV файлы с твитами)

## Установка и запуск

### Требования
- .NET 8.0 или выше
- VS CODE + Plugin PolyglotNotebook (Jupyter) с поддержкой C# 
- Вообще необходима среда .NET Interactive (возможно ее придется ставить отдельно, но вообще он должен идти вместе с SDK)

### Установка зависимостей
```bash
# Установка .NET (если не установлен)
# macOS: brew install dotnet
# Windows: скачать с https://dotnet.microsoft.com/en-us/download

# Проверка версии
dotnet --version
```

### Запуск через PolyglotNotebook
1. Откройте файл `cssharp_gorovenko.ipynb` в VS CODE (Jupiter)
2. Убедитесь, что установлен PolyglotNotebook
3. Запустите ячейки последовательно (Shift+Enter)
