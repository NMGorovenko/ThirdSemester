# ЛР3 — Векторные представления (LSA, Word2Vec, Doc2Vec)

Лабораторная работа расширяет решения из ЛР2: на тех же размеченных твитах обучаются три семантических анализатора (LSA, Word2Vec, Doc2Vec), строится их сравнение и демонстрация на пользовательских данных.

## Требования
- .NET 7 SDK или новее
- Jupyter Notebook (>=6.5) с установленным `dotnet-interactive`
- Git LFS (для загрузки train/test датасетов)
- Docker Desktop + VS Code (для сценария с dev container)

Запустить ноутбук целиком из CLI:
```bash

  --output out_exec_lab3.ipynb --output-dir src
```

В конце ноутбука есть блок `customTexts`. Добавьте нужные строки в массив, выполните ячейку и получите предсказания всех моделей. Ту же ячейку можно вызвать классически и в headless прогоне — тексты и детализированные ответы появятся в выводе.

## Примеры работы анализаторов
### Качество на тестовом наборе
`src/lab3.ipynb` фиксирует метрики (F1 приведена для класса «positive»):

| Метод     | Accuracy | F1    | AUC  |
|-----------|----------|-------|------|
| LSA       | 0.827    | 0.835 | 0.910|
| Word2Vec  | 0.687    | 0.674 | 0.752|
| Doc2Vec   | 0.549    | 0.621 | 0.555|

LSA (TF-IDF + PCA + логистическая регрессия) даёт наилучшее качество, Word2Vec проигрывает по точности, но устойчивей на «шумных» примерах, Doc2Vec значительно уступает без дополнит. эпох и регуляризации.

### Фрагменты из тестов

- Документ «Shanghai is also really exciting…» (истинная метка: positive):
  - LSA → positive (p=0.829)
  - Word2Vec → positive (p=0.527)
  - Doc2Vec → positive (p=0.558)
- Документ «My bike was put on hold…» (true negative):
  - LSA → negative (p=0.416)
  - Word2Vec → negative (p=0.409)
  - Doc2Vec → negative (p=0.437)

### Пользовательские тексты

| Текст пользователя | LSA | Word2Vec | Doc2Vec |
|--------------------|-----|----------|---------|
| "Absolutely love the latest update, everything works flawlessly and makes me so happy!" | positive (p=0.968) | positive (p=0.861) | positive (p=0.508) |
| "Customer support was terrible: half of my order was missing and nobody apologized." | negative (p=0.078) | negative (p=0.396) | negative (p=0.418) |

LSA и Word2Vec уверенно распознают позитивный отзыв, Doc2Vec остаётся ближе к порогу (0.5) и демонстрирует меньший запас уверенности.

## Сравнение подходов
- **LSA** — требует классическую предобработку, но обеспечивает лучшую точность и AUC; хорошо объясним через веса TF-IDF и компоненты PCA.
- **Word2Vec** — обучает собственные эмбединги; при среднем по токенам менее стабилен по точности, но возвращает более «гладкие» ближайшие примеры по смыслу.
- **Doc2Vec** — даёт самостоятельные документные вектора, однако при малом числе эпох и без регуляризации быстро переобучается и проигрывает по метрикам; подходит для быстрого поиска похожих отзывов, но требует дополнительного fine-tune.

## Что делает ноутбук
- Нормализация текста: токенизация, лемматизация, стоп-слова.
- Формирование обучающей выборки (≈4k train, весь test) и словарей.
- LSA: TF-IDF → PCA (300 компонент) → L2 → логистическая регрессия, расчёт метрик.
- Word2Vec: собственный skip-gram с negative sampling (2 эпохи), усреднение векторов, классификация.
- Doc2Vec: DBOW подобие (3 эпохи, 4 негативных образца), прямое использование векторов в классификаторе.
- Поиск ближайших train-документов к запросам и визуализация в 2D проекциях.

После прогонов метрики и примеры доступны прямо в `src/out_exec_lab3.ipynb`, а графики — в `results/`.
