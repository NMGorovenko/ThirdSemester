Технологический стек работы:

- C# / .NET:
  - Основной язык разработки логики симулятора в Unity.
  - Реализация скриптов для управления сценами, транспортными средствами и взаимодействия с ML-Agents.

- Unity:
  - Платформа для создания 3D-сцен, моделирования физики и визуализации движения машинок.
  - В Unity создаются трассы, размещаются виртуальные сенсоры и реализуется игровой цикл эпизодов обучения.

- Unity ML-Agents:
  - Фреймворк, который связывает среду Unity с нейросетевыми моделями.
  - Позволяет организовать обмен наблюдениями и действиями между симулятором и Python-средой обучения.

- Python:
  - Язык для реализации нейросетевых моделей и тренировочных скриптов.
  - Используются фреймворки глубокого обучения (например, PyTorch или TensorFlow) для обучения агентов.

- Протоколы взаимодействия (например, gRPC / HTTP API):
  - Используются при необходимости вынести часть логики или инференс модели в отдельный сервис.
  - Обеспечивают обмен данными между симулятором, тренировочным сервером и реальной машинкой.

- Аппаратная платформа:
  - Небольшая реальная машинка с возможностью программного управления.
  - Наличие камеры и каналов управления рулём, газом и тормозом.
