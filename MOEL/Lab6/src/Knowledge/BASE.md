ОСНОВНАЯ ИДЕЯ РАБОТЫ (кратко, что ты должен уметь объяснить):
- В Unity создаётся симулятор с трассами и виртуальными беспилотными машинками.

- Далее сравниваются результаты в симуляции и в реальном мире, оценивается качество переноса политики управления.

2. ТЕХНОЛОГИЧЕСКИЙ СТЕК:
- C# и .NET — основной язык и платформа для логики симулятора в Unity.

- Python — язык, на котором могут быть реализованы нейросетевые модели и тренировочные скрипты.

- Дополнительные библиотеки Python (фреймворки для нейросетей, такие как PyTorch или TensorFlow) — используются для обучения и инференса модели.

3. СТРУКТУРА ПРОЕКТА В UNITY:
- Папка `Assets/Scenes` — сцены с трассами и конфигурациями симуляций.
- Папка `Assets/Scripts/Core` — базовая логика (менеджеры сцен, игрового цикла, конфигурации симуляции).
- Папка `Assets/Scripts/Vehicles` — скрипты управления виртуальными беспилотными автомобилями (динамика, ввод управляющих воздействий от агента).
- Папка `Assets/Scripts/AI` — обёртки для нейросетевых агентов и интеграции с ML-Agents или внешним API.
- Папка `Assets/Models` — простые (лёгкие) 3D-модели.
- Папка `Assets/ExternalModels` — тяжёлые модели, которые удобно хранить отдельно (например, под LFS).
- Папка `Assets/Materials` — материалы для визуализации.
- Папка `Assets/Prefabs` — префабы машинок, элементов трассы и окружения.
- Папка `Assets/Plugins` — плагины (в том числе Unity ML-Agents).

4. ЛОГИКА ОБУЧЕНИЯ АГЕНТОВ:
- Агенты в Unity получают состояния из симуляции (положение на треке, скорость, изображение с камеры и т.п.) и выдают управляющие действия (руль, газ, тормоз).
- Награда строится таким образом, чтобы поощрять стабильное движение по трассе, прогресс вдоль трека и избегание столкновений и вылетов.
- Обучение происходит в Python с использованием ML-Agents и алгоритмов обучения с подкреплением, при этом Unity выступает в роли среды для генерации опыта.

5. ПЕРЕНОС НА РЕАЛЬНУЮ МАШИНКУ:
- После завершения обучения нейросетевой модели в симуляции её параметры сохраняются.
- На реальной машинке разворачивается инференс-модуль, который принимает данные с реальных сенсоров (например, камеры) и выдаёт управляющие команды.
- Проводится эксперимент на реальной трассе и сравнение поведения с симуляцией (скорость прохождения трассы, количество ошибок, устойчивость движения).

6. УНИКАЛЬНОСТЬ И НОВИЗНА:
- Ориентация не просто на абстрактный симулятор, а на полный цикл: от обучения в виртуальной среде до проверки на реальном беспилотном платформенном прототипе.
- Гибкая архитектура симулятора в Unity, позволяющая создавать разные сцены с трассами и конфигурациями окружения.
- Возможность использовать как встроенные механизмы ML-Agents, так и собственные протоколы связи (например, gRPC) с внешними нейросетевыми сервисами.
